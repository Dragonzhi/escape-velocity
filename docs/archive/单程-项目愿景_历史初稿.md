# 《单程》Escape Velocity · 项目愿景

> Dora SSR × Agent 社区小游戏征集 · 参赛项目
> 中文名《单程》｜英文名 **Escape Velocity**｜仓库名建议 `escape-velocity`
> 整理日期：2026-09-22

---

## 0. 一句话

**用一次发射，借行星的力，把一枚探测器送出太阳系。**

---

## 1. 它是从哪长出来的

- **机制原型**：保龄球。一次输入决定方向与力度，引发连锁，最后分级结算。
- **题材来源**：旅行者 1 号与引力弹弓（gravity assist）。1977 年发射，此后再无回头路。
- **转换原则**：魂不动，壳全换，成品里不该有人看出保龄球的影子。

这套机制的内核是：**一次输入 → 投射物在空间中引发连锁 → 结果分级**。
四件事不能动：一次性、间接作用、连锁、结果有档次。

---

## 2. 核心体验

三个词：**一次、借力、不可撤销。**

玩家不是一个动作高手，是一个任务规划员。他要做的事，是在一张会动的星图上，找到那条唯一正确的线，然后赌上它。

---

## 3. 玩家在做什么（核心循环）

1. 关卡开始，看到出发星、目标星，以及沿途行星的位置与运动。
2. 手指按住探测器拖动，屏幕上实时画出**预测轨迹**，被沿途引力掰弯。
3. 反复调整，让轨迹擦过目标行星的**后方**。
4. **松手**。这就是那一次，此后无法修正。
5. 时间流动，探测器自己飞出去，玩家只能看着。
6. 结果揭晓：借力成功被甩走 / 错过 / 撞毁。进入下一关。

**观赏不是玩法，观赏是奖励。** 玩的部分压在松手之前那一秒。

---

## 4. 引力弹弓规则（玩家要学的全部）

这是游戏里唯一需要理解的物理，也是唯一的教学点：

- **从行星运行方向的后方掠过 → 加速**
- **从行星前方掠过 → 减速**
- **离得越近效果越强，太近就撞毁**

口诀版：**从行星的屁股后面抄过去。**

原理一句话：探测器从行星身上偷了一点公转动能，行星太大，损失可以忽略。

---

## 5. 关卡曲线

**判断标准：新关卡 = 新决策。** 换星球、拉长距离都是假难度，不用来当关卡主线。

| 关卡 | 新引入的旋钮 | 玩家学到什么 |
|---|---|---|
| 1 · 直飞 | 无引力 | 拖、看线、松手 |
| 2 · 第一次弯曲 | 一颗静止行星 | 轨迹会被引力掰弯 |
| 3 · 从背后抄过去 | 必须借力才到得了 | 后方加速、前方减速 |
| 4 · 它动了 | 行星开始公转 | 发射时机开始重要 |
| 5 · 两连弹 | 两颗行星 | 规划多段弹弓 |
| 6 · 贴着过去 | 容差收窄 | 精度 |

**备选（时间够再加）**

| 关卡 | 旋钮 | 学到什么 |
|---|---|---|
| 7 · 被带偏 | 中途多一颗行星 | 躲暗流 / 化干扰为助力 |
| 8 · 出去 | 全部串联 | 冲出太阳系 |

**六关定稿，七八备选。** 每关只教一件事，做扎实。

---

## 6. 视觉风格

**low poly 3D，纯色 flat 材质，不贴图。**

| 元素 | 做法 |
|---|---|
| 星球 | 球体；土星加环（白送的关卡风景） |
| 探测器 | 小三角 / 小型卫星，简到极致 |
| 轨迹 | 一条发光曲线，**全场最重要的视觉元素** |
| 背景星空 | 一层星空穹顶，可选在引力源附近做 UV 扭曲 |
| 引力源（可变体） | 纯黑球体 + 自发光光环 + 被吸入的粒子 |
| 光源 | 一盏方向光，阴影可关 |
| 配色 | 少色、高明度差、暗底亮线 |

不贴图这一条同时解决三件事：Blender 里只摆几何体、包体最小、渲染最省。

## 7. 叙事与情感

题材的真实重量是这个项目最不该浪费的东西。

- **开场**：金唱片、1977 年的发射。
- **关卡之间**：一句任务简报，让每一次松手都有分量。
- **终章**：借完全部行星，探测器飞出去，镜头回望，画面里只剩一颗小小的暗淡蓝点。

这可能就是全片最该花钱的那几秒。

## 10. 技术简化策略

**物理砍成 2D，画面保持 3D。**

- 真实轨道都挤在黄道面附近，所以引力计算可以在一个平面内做：行星视作点质量，引力按平方反比施加，固定时间步积分，几十行代码。
- 渲染仍是 3D：镜头斜着看这个平面，行星是球体，轨迹是发光的线。
- **预测轨迹与真实轨迹共用同一套积分**，改一个参数立刻能看见结果，调试成本极低。
- 第一版**不区分加速与减速**，只把"轨迹在行星附近明显被掰弯"做出来。
- 物理真实度不是评分项，手感才是。先让它看起来对，不要一上来追求算得对。

---

## 11. 相机策略（要早试）

探测器会飞出很远，竖屏空间有限。两条路：

- **发射前**：全局视角，看清出发星、目标星与行星位置。
- **飞行中**：跟随探测器并逐渐拉远。

一关之内可能要切换两种视角。**这是最该先验证的技术点之一，别等关卡摆好才发现镜头不会动。**

---

## 12. 时间冻结还是流动（待定）

调整轨迹时，行星是停下来等你想，还是继续走？

- **冻结**：像解谜，可慢慢试，对触屏和新手友好。
- **流动**：像动作，紧张感翻倍。

**建议第一版用冻结**，后面关卡再放出行星移动。这个决定直接影响整体手感，早定为好。

---

## 13. 视觉效果的降级阶梯

按成本从低到高，从便宜的开始做：

1. **引力源 + 轨迹被掰弯**（必做，这本身就是玩法）
2. **引力源本体**：黑球 + 发光环 + 粒子（必做，纯几何与材质，不需要后处理）
3. **背景星空 UV 扭曲**（目标，只影响一张背景面片，不做全屏后处理）
4. **全屏引力透镜后处理**（梦想，留给最后一两天，做不出来直接砍）

**不要把这四级都写进第一版需求**，那会拖住整个项目。

> 技术备注：Dora SSR 提供 `Shader`（运行时编译 Vertex/Fragment/Compute）与 `RenderTarget`（渲染到纹理），第 4 级在原理上可行，但需要自己搭后处理管线。3D 功能 2026 年 8 月才上线，成熟度有限。

## 15. 验收标准

- [ ] 六关全部可通关，每关引入一个新决策
- [ ] 全流程触屏可完成（开始 → 游玩 → 结算 → 重开）
- [ ] 松手后不可修正，"一次"的约束真实生效
- [ ] 同一个输入每次结果一致（可预测、可学习）
- [ ] Web 导出后可在浏览器完整游玩一局
- [ ] 手机上触控与缩放正常，按钮可见可点
- [ ] 60 秒内能讲清玩法
- [ ] Web 包体积在预算内

---

## 16. 风险清单

| 风险 | 应对 |
|---|---|
| 3D 是新功能，从没碰过 | 先做裸测，跑不通立刻换航道 |
| Web 导出 3D 性能未知 | 裸测阶段就验证帧率 |
| 引力参数调不出手感 | 先做"看起来对"，用固定时间步简化积分 |
| 相机跟不上探测器 | 与核心循环同期验证，不后置 |
| 后处理做不出来 | 已在降级阶梯里排最后，砍掉不影响主体 |
| 关卡过多做不完 | 六关定稿，七八只当备选 |

## 附：项目边界

**做**：一个竖屏、单指、六关的物理规划小游戏，讲一次不可撤销的告别。

**不做**：真实的轨道力学模拟、自由漫游的太空沙盒、多人在线、复杂后处理管线。
