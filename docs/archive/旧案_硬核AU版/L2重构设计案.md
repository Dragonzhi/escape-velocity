## 一、 核心定位与航天历史还原

### 1. 历史原型：人类引力弹弓纪元的开端
* **任务背景**：1973年11月发射的水手10号（Mariner 10）是人类历史上第一艘利用**行星引力弹弓（Gravity Assist）**变轨的探测器，也是人类首个造访水星的使者。
* **物理本质：逆向引力辅助（前向减速弹弓）**：
  水星深陷太阳引力深井。如果仅靠火箭自身动力直飞水星，所需发射 $\Delta v$ 甚至超过飞往冥王星的极限。水手10号通过轻微点火飞往金星，并从**金星公转方向的前方**切入其引力井。金星在探测器身后反向拖拽，将其日心速度大幅削减，使得轨道的近日点由 0.723 AU 骤降至 0.387 AU，成功跌入水星轨道。
* **三部曲承上启下**：
  全游戏精简为 3 关史诗三部曲后，L2 承担着全游戏**从地月霍曼转移（L1）跃迁到行星引力弹弓（L2）的关键教学与核心玩法体验**，直通 L3（旅行者2号大巡游）。

## 二、 硬核借力物理剖面与数值规格

| 物理要素 | 规格与数值 | 设计依据与说明 |
|---|---|---|
| **出发状态** | $1.0\text{ AU}$ 地球公转轨道 $(0, 80)$，圆轨速度 $v_0 = (-30.0, 0)$ | 探测器在地球轨道待命，配置母星地球作为视觉锚点 |
| **初始发射 $\Delta v$ 预算** | **$3.50$ 单位**（满力上限） | 霍曼转移至金星需要 $\Delta v \approx 2.5 \sim 2.8$；留有微调余量，严禁蛮力直飞 |
| **金星引力井参数** | $r_{orbit} = 57.87\text{ AU}$，周期 $10.31\text{ s}$，希尔球 $r_H \approx 0.54$ | 真实天文常数（`Scale.ts` 导出） |
| **金星借力走廊** | **$r_{peri} \in [0.03, 0.40]$ 单位** | **硬核核心**：必须精确切入金星希尔球前向区域。太远（$>0.40$）无法获得足够减速，太近（$<0.0032$）坠毁在大气层 |
| **水星到达容差** | **$\text{tolerance} = 4.0\text{ 单位}$** | 最终目标拦截圈，2D 规划层有清晰青白到达环 |
| **发射时间窗口** | 会合周期 $T_{syn} \approx 26.8\text{ s}$，`timeWindow.span = 27` | 时间轴覆盖一个完整会合周期，保证滑动日期必然能找到一次黄金发射窗口 |

## 三、 慢速从容的仪式感 3D 倒叙运镜（约 6.5 秒）

只在首次进入关卡时播放一次，关内重试不重放，支持轻触屏幕跳过（`Tap to skip`）：

1. **第一幕：目标水星特写 (Mercury, 0.0s ~ 2.2s)**：
   - 相机以 35° 仰角环绕水星，展现最新绑定的 `Planet_Mercury.glb` 与 `mercury.jpg` 高对比陨石坑地貌与冷峻晨昏线；
   - 环绕青白色脉冲到达圈，字幕呈现：`【勘测终点：水星 (Mercury) · 荒凉焦土】`。
2. **第二幕：逆向溯源飞掠金星 (Venus Flyby, 2.2s ~ 4.7s)**：
   - 相机平滑拉升并高速倒向穿梭，跨越 27 个世界单位从 0.387 AU 逆向飞向 0.723 AU；
   - 镜头近距离擦过金星厚重的金色云层，展现行星引力井的庞大体量；
   - 字幕呈现：`【关键中继：金星引力弹弓 (Venus Gravity Assist) · 逆向减速】`。
3. **第三幕：归巢地球与探测器 (Mariner 10, 4.7s ~ 6.5s)**：
   - 镜头减速平滑俯冲回 1.0 AU 地球轨道，以母星蔚蓝半球为背景；
   - 水手10号探测器的太阳能翼与高增益天线微光闪烁，呈现待命状态；
   - 字幕呈现：`【出发地：地球公转轨道 (1.0 AU) · 水手10号发射待命】`。
4. **切入 2D 规划模式**：
   - 运镜自然垂直升起并展开为 2D 轨道线稿图层，左下角控制组 `[−]`、`[FIT]`、`[+]` 与任务抽屉平滑亮起。

## 四、 2D 规划与视觉资产

1. **资产登记与绑定**：
   - 水星模型：`Assets/Model/Planet_Mercury.glb`（外接半径 1.000）；
   - 水星贴图：`Assets/Image/mercury.jpg`；
   - `Scene.ts` 配置：`MODEL_RADIUS` 登记 `{ name: 'Planet_Mercury', k: 1.000 }`，`PLANET_TEX` 登记 `{ name: 'Planet_Mercury', base: 'mercury.jpg' }`；
   - 视觉半径：水星设置为 `0.022`，金星设置为 `0.028`，地球设置为 `0.030`。
2. **2D 缩放与信标**：
   - 默认 `FIT`：自适应包络太阳、水星、金星与地球，统揽整条内侧减速航线；
   - 放大 `[+]`：用于精细微调金星近心点，观测微小的点火偏角如何大幅改变借力后的出射轨迹；
   - 水星目标信标：当缩放拉大时，屏幕边缘以青色信标箭头指示水星实时方位。

## 五、 “三枚火箭 🚀🚀🚀”挑战规格

* 🚀 **【一星·双星连线】（使命达成）**：
  成功切入金星引力走廊并飞掠/抵达水星目标容差圈；
* 🚀🚀 **【二星·推进节制】（精打细算）**：
  发射点火消耗 $\Delta v \le 2.65$（预算 3.50 的 75% 以下，严禁蛮力推进）；
* 🚀🚀🚀 **【三星·教科书借力】（传奇领航）**：
  金星交会近心点距离 $r_{peri} \le 0.35$（深入金星引力深井有效区，实现教科书般的前向减速弹弓）。

## 六、 施工与验收清单

1. **L2-0 数值与相位求解**：使用引力两段求解算法解出金星与水星对齐的黄金相位 `PH.venus` 与 `PH.mercury`，确保在 `timeWindow` 内有稳定解；
2. **L2-1 资产与材质绑定**：在 `Scene.ts` 中接入 `Planet_Mercury.glb` 与 `mercury.jpg`；
3. **L2-2 慢速三段式运镜**：在 `Game.ts` 中针对 L2 编写水星 ➔ 金星 ➔ 地球探测器的 6.5s 仪式感镜头，并支持轻触跳过；
4. **L2-3 全要素真机验收**：运行单测与截屏脚本验证 L2 完整游玩链路。
