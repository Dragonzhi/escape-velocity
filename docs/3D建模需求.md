# 《单程 · 街机引力弹弓》3D 建模需求单 (BlenderMCP 交付指南)

> **交付对象**：TraeWork 工程师 / BlenderMCP 自动化建模流程。
> **目标**：为全新的“街机引力弹弓”游戏性版本制作关键 3D 道具与环境障碍模型，即插即用。
> **交付格式**：单个自包含的二进制 **`.glb`** 文件（内嵌贴图与材质）。

---

## 一、 技术规格与通用约束（必读硬指标）

| 指标 | 规格标准 | 说明 |
|---|---|---|
| **导出格式** | **GLB (glTF 2.0 Binary)** | 统一采用单个 `.glb` 交付，贴图内嵌，避免散落文件解析失败 |
| **尺寸基准** | **单位球归一化 ($R_{bound} = 1.0$)** | 无论实际多大，导出时外接球半径统一缩放为 **1.0**，代码层按需 scale |
| **原点设置** | **几何几何中心 (Origin at Center)** | 模型的原点 $(0,0,0)$ 必须精确位于物体几何中心 |
| **面数预算** | **每个模型 300 ~ 1500 三角面 (Tris)** | 竖屏移动端小游戏，注重轮廓感与性能，严禁高模细分 |
| **材质标准** | **PBR Metallic-Roughness** | 支持 BaseColor、Roughness、Metallic，关键道具必须配置 **Emissive（自发光）** |
| **坐标系朝向** | **Y-Up, -Z Forward** | Blender 导出 glTF 时保持默认转换设置（+Y 为上） |

## 二、 新增资产制作清单（3 款关键道具）

### 1. 太空障碍陨石 · `Asteroid_Rock.glb`
* **用途**：阻挡在发射点与目标之间的直线路线上，飞船撞击即爆炸坠毁，逼迫玩家使用引力转弯绕路。
* **视觉参考**：
  * 不规则太空小行星碎块、多面体陨石，带有凹凸不平的低多边形切面或陨石坑质感；
  * 配色：深灰褐色、冷铁矿石质感，局部带微弱的高光反光（粗糙度 0.85，金属度 0.15）。
* **面数**：500 ~ 800 三角面。
* **文件存储路径**：`Assets/Model/Asteroid_Rock.glb`。

### 2. 收集星尘晶体 · `Star_Crystal.glb`
* **用途**：每关错落悬浮 3 颗，飞船飞掠穿过即收集（🌟🌟🌟 三星评价核心目标）。
* **视觉参考**：
  * 八面体（Octahedron）或六棱双锥能量水晶，线条硬朗锐利，类似科幻太空星尘核心；
  * **材质关键**：必须配置强烈的 **Emissive（自发光）**，颜色为耀眼的金黄色（`#FFD700`）或青蓝色（`#00FFFF`），在暗黑宇宙中醒目闪烁。
* **面数**：200 ~ 400 三角面。
* **文件存储路径**：`Assets/Model/Star_Crystal.glb`。

### 3. 终点星门靶心 · `Target_Gate.glb`
* **用途**：终点目标星球上空的轨道对接星门，飞船切入星门内部即触发 `PERFECT INSERTION!` 胜利结算。
* **视觉参考**：
  * 环形机械太空星门 / 轨道能量环，中心留空（供飞船穿过）；
  * 外环带有 3~4 组机械推进器节点或能量发生器柱；
  * 内环边沿带有一圈青绿色（`#00FF88`）的能量脉冲自发光条带。
* **面数**：800 ~ 1200 三角面。
* **文件存储路径**：`Assets/Model/Target_Gate.glb`。
