## 一、一句话

**同一套物理，去不同的地方。** 玩家在 2D 线稿图上规划一条路，按下发射，然后在 3D 里看着自己
被一颗行星甩弯 —— 那一下是这个游戏的核心瞬间。

## 二、定稿的十条（讨论逐条确认）

| # | 议题 | 结论 |
|---|---|---|
| 1 | **核心瞬间** | **掠过行星被甩弯**（速度与方向被天体改掉）。它是 3D 的回报，不是 2D 的任务 |
| 2 | **飞行怎么演** | 掠过时**自动近景慢动作**（1/4 速、贴近行星），平时正常速度；给玩家 1×/2×/4× 兜底 |
| 3 | **两个视图** | **2D 线稿示意图 = 规划**；**3D = 观赏与回报**（发光太阳、真实比例、掠过特写） |
| 4 | **切换** | 自动为主：进关/瞄准在 **2D** → 按下发射**自动切 3D** → 飞行与结算留 **3D** → 重试回 **2D**；右下角保留手动切换按钮 |
| 5 | **方向与快慢** | 沿轨道**流动的光点**：光点移动方向 = 公转方向，移动快慢 = 角速度 |
| 6 | **一眼可读** | ① 下一站在哪 ② 这条线够不够得着 ③ 什么时候发射 ⑤ 燃料够不够 ⑥ 还要飞多久。（④ 掠过距离**不进 2D**，留给 3D 的惊喜） |
| 7 | **物理统一** | 太阳、在动的行星、引力弹弓、时间轴、碰撞 —— **从第一关起全部在场**，不再有"这一关才引入"的机制 |
| 8 | **关卡形态** | **六个独立任务**：每关都从地球轨道出发，去一个不同的地方，关与关之间不连缀 |
| 9 | **尺度** | 守真实比例，不为画面放大行星；靠相机、光晕、取景预算讲故事 |
| 10 | **押注口径** | 2D 做**简化版**；时间优先给**掠过慢动作与镜头**；终章与按钮图标化按剩余时间决定 |

### 六站清单

| 关 | 目的地 | 距离（平面单位） | 要穿的中继节点 | 探测器 | 
|---|---|---|---|---|
| 1 | **月球** | 近地（月球轨道 ≤ 15，希尔球内） | 0 | **太阳能板版** |
| 2 | **金星** | 55（**向内飞**） | 0 | **太阳能板版** |
| 3 | **木星** | 105 | 0（第一次远航） | **太阳能板版** |
| 4 | **土星** | 135 | 1（木星） | **RTG 版** |
| 5 | **天王星** | 165 | 2（木星、土星） | **RTG 版** |
| 6 | **海王星** | 195 | 3（木星、土星、天王星） | **RTG 版** |

**探测器有两个版本（真实工程依据）**：太阳能板的功率 ∝ 1/r²，木星以外基本没有意义 ——
所以近处任务（月球 / 金星 / **木星**，Juno 号就带着大太阳能板去过木星）用**太阳能板版**，
远处任务（土星 / 天王星 / 海王星）换成 **RTG 核电池版**（Voyager 就是这么飞的）。
两版都是"机体 + 天线"两个文件（引擎拿不到 glTF 子节点，见 `docs/模型交接_Trae.md`）。

**终章「暗淡蓝点」**接在第 6 关成功之后（飞出太阳系 → 回望地球缩成一点），**不再单独做成一关**。

> 为什么这样排：六个目的地刚好用满现有六条轨道（55/80/105/135/165/195），距离单调递进；
> 难度不靠"新机制"而靠**要穿几个节点 + 距离 + 允许的误差**。第 1 关是唯一一次"近景"，
> 因为月球必须在希尔球（≈18 单位）内才符合力学。

## 三、六关舞台表（写文档时的验收基线）

每一关都必须能回答这四个问题：**2D 里看到什么 / 3D 里演什么 / 玩家要决定什么 / 难度从哪来**。

| 关 | 2D 规划视图里必须有什么 | 3D 里演什么 | 玩家要决定 | 难度来源 |
|---|---|---|---|---|
| 1 月球 | 地球与月球两个图钉、月球轨道（流动光点）、预测线、到达圈 | 近距离地月系：地球占画面一角、月球绕行、太阳只在远处发亮 | 什么时候点火（月球在动，要预判）+ 方向 | 预判一个快速移动的小目标；飞行只有 ~2 秒 |
| 2 金星 | 太阳（中心）+ 地球轨道 + 金星轨道 + 图钉；**向内的那条线** | 向内坠落：太阳在画面里变大、刺眼、你的速度越来越快 | 什么时候收（太阳会一直加速你） | 下降段的能量控制 |
| 3 木星 | 木星轨道 + 高亮目标图钉 + 到达圈 | 第一次真正的行星际飞行：太阳缩小、木星长大、掠过被掰弯 | 从哪一侧掠过 | 一次借力的方向性 |
| 4 土星 | 木星（中继）+ 土星（目标）两个图钉 + 两条轨道 | 掠过木星改向，再滑向土星 | 借木星把自己送出去 | 两个节点 |
| 5 天王星 | 木星/土星（中继）+ 天王星（目标） | 连续两次借力，越飞越远 | 连续借力的顺序 | 三个节点 |
| 6 海王星 | 木星/土星/天王星（中继）+ 海王星（目标）+ 四颗连珠的提示 | 一次点火串四颗巨行星 → 飞向星际空间 | 一次点火串到底 | 四个节点 + 精度 |

**每一关都有时间轴**（日期会改变行星的排布，因此改变这条路通不通），不再只有 L4/L6 才有。

## 四、这次转向作废了什么（诚实结算）

| 作废 | 换成 |
|---|---|
| L1 的"地月局部系"（无太阳、地月放大到 6.0/3.4、月球轨道 100） | 太阳常年在场（对地月只表现为**潮汐扰动**，约 4 单位/秒²，预测线会画出来）；地月缩小到月球轨道 ≤15 |
| "每关只加一个新决策"的阶梯（出发/修正/弹弓/窗口/大巡游/单程） | 六个独立任务，难度来自旅程 |
| "只有 L4/L6 有时间轴"的特例 | 每关都有时间轴（统一 UI） |
| L6 = 逃逸关（`kind:'escape'`） | L6 = 海王星（行星目标）；逃逸归终章 |
| 六关全部相位/容差/成功率的既有数值 | 在新设计下**重解一遍**（工具齐全：`tools/level-phases.mjs`、`tools/level-sweep.mjs`） |

## 五、剩余时间怎么用（截止 2026-09-29 23:59，约 2.5 天）

押注口径（讨论第 10 题选 B）：**2D 做简化版，时间优先给掠过慢动作与镜头**。

1. **D1 上午**：统一物理 + 六站重排（起始点/相位/容差重解 + 扫掠 + 引擎验收）→ 六关能通；
2. **D1 下午**：2D 规划视图简化版（线稿轨道 + 图钉 + 预测线 + 拖拽瞄准 + 自动/手动切换）；
3. **D2 上午**：沿轨道流动的光点 + 掠过慢动作与镜头；
4. **D2 下午**：终章「暗淡蓝点」（能压就压成一屏）+ 开始 S4 提交物；
5. **D3**：S4 提交物（图标 / 封面 / 演示视频 / 公开仓库）+ 全量回归。

**砍线顺序**（从后往前砍）：终章细节 → 按钮图标化 → 2D 的标注与时间轴提示 → 慢动作特写细节
→（保）2D 视图 + 统一物理 + 六站可通 + S4 提交物。
