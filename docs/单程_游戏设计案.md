# 一、 项目一句话与愿景

## 1.1 一句话定义
> **用一次发射，借行星的力，把一枚探测器送出太阳系。**

《单程》是一款面向竖屏移动端 / Web 端的纯物理轨道规划独立游戏。玩家扮演深空航天控制中心的领航员，在发射前利用有限的推进燃料与行星发射时间窗完成弹道规划；**发射之后，探测器由真实天体物理引力驱动，所有决定只能向前、不可撤销。**

## 1.2 设计北极星与核心情感
1. **“所有决定都只能向前，不可撤销”**（Forward-only Commitment）：
   - 不设自由飞行手柄，不设空中任意微调；
   - 玩家的操作极度克制：发射前的初速规划、发射日期的窗口微调，以及（若为轨道器）飞行临界期仅此一次的制动点火；
   - 所有的结果均由物理法则自然判定，带来纯粹的决定宿命感。
2. **“掠过行星被甩弯”是核心高潮**：
   - 探测器贴近行星近心点时，受行星深重引力牵引发生剧烈弯折与速度跃升——这是 3D 视觉与听觉给玩家最核心的奖励。
3. **“暗淡蓝点”的终局史诗**：
   - 游戏不是简单的打靶通关，而是以人类深空探测（Voyager、Galileo、Cassini、New Horizons）为叙事底色的浪漫史诗；
   - 历经重重引力弹弓飞出太阳系后，回望家园地球缩成一个像素的“暗淡蓝点”，完成一场壮丽的单程远征。

## 1.3 交付目标规格
* **引擎**：Dora SSR（v1.9.3+）
* **语言**：TypeScript（编译为 Lua 由引擎执行）
* **形态**：竖屏、单指触屏操控（自适应横屏/不同宽高比）
* **导出**：Web (HTML5) 并通过真机测试
* **开源协议**：AGPL-3.0-only
* **美术约束**：纯代码生成与自制 Low-poly glTF 几何模型 + 贴图，无第三方商业素材依赖。

# 二、 核心机制与双载具模式

## 2.1 规划与观赏的双视图体系
《单程》采用“**2D 规划线稿 ⇄ 3D 沉浸观赏**”的双层视听设计：

```text
[ 进关 / 瞄准阶段 ] ──────────> [ 发射瞬间 ] ──────────> [ 飞行与慢镜头特写 ] ──────────> [ 终点与结算 ]
   2D 俯视规划线稿                 自动平滑切入                   3D 动态跟随 / 伴飞镜头               3D 观赏 + 结果浮现
 (调方向 / 时间 / 读数)            (视角俯冲过渡)               (发光太阳 / 晨昏线 / 甩弯)            (重试回到 2D 规划)
```

* **2D 规划视图（Blueprint View）**：
  * 线稿轨道圆环、天体图钉与动态公转流动光点（光点流动方向 = 公转方向，速度 = 真实角速度）；
  * 目标天体到达判定圈、发射前预测线与高亮制动窗口；
  * 提供一眼可读的信息：下一站在哪、航线是否可达、何时发射、燃料预算、飞行耗时。
* **3D 观赏视图（Spectator View）**：
  * 真实 AU 比例空间、发光自发光太阳与大气光晕日冕面片；
  * 真实天体贴图与行星晨昏光影交界线；
  * 彗星式渐细粒子尾迹与掠过天体时的特写镜头。
* **切换机制**：进关/重试自动在 2D 瞄准，按下发射自动切入 3D 运镜，界面保留手动一键切换按钮。

## 2.2 载具双模式：飞掠器 vs 轨道器
为了还原深空探测的两大经典任务形态，游戏提供两种载具模式：

| 模式 | 现实代表 | 玩法机制 | 核心体验 |
|---|---|---|---|
| **飞掠型 (Flyby Probe)** | Voyager 1/2<br>New Horizons | $100\%$ 燃料预算全部用于地面发射初始冲量；松手发射后不再有主动操作，纯凭引力弹弓加速甩向下一站或深空。 | **“我借你的力，然后继续向前。”** |
| **轨道器型 (Orbiter Probe)** | Galileo (木星)<br>Cassini (土星)<br>MESSENGER (水星) | 预留一部分机动预算分配给在轨制动发动机（$\Delta v_{brake}$），初始发射冲量相应折减；**飞行途中赋予玩家仅此一次不可撤销的逆向制动机动**。 | **“我借你的力，然后决定留下。”** |

## 2.3 飞行期制动机动（方案 A：制动窗口机制）

在轨道器模式下，飞行不再是单纯的挂机等待，而是引入了类似《愤怒的小鸟》释放特技的临界心流：

```text
发射 ──(冷白虚线)──> [ 飞入目标引力井 ] ══(金色脉冲制动窗口)══> [ 飞离 / 逃逸 ]
                                 │
                         玩家按下 [ BRAKE ]
                                 ↓
                     逆向点火爆发，瞬时减速
                                 ↓
                ┌────────────────┼────────────────┐
                ↓                ↓                ↓
            Crash (坠毁)    Capture (稳定入轨)   Escape (逃逸)
```

### 1. 发射前预测线（分段呈现）
* **基础飞掠段**：冷白 / 浅青虚线，展示未经主动制动的自然飞掠轨迹。
* **制动窗口段（Braking Window）**：琥珀金脉冲发光光带。该段由纯函数预积分求得——**只要探测器在该段轨迹内按下制动，其剩余动能即可被引力捕获为稳定环绕轨道**（满足束缚能量 $E_{rel} < 0$ 且近拱点 $r_{peri} > R_{body} \cdot (1 + \text{安全缓冲})$）。

### 2. 飞行期慢镜头透镜联动（Slow-mo Lens）
* 当探测器飞抵目标天体引力影响区或接近制动窗口起点时，播放倍速平滑衰减至慢动作档位（`0.25x`），相机自动贴近天体形成特写；
* 将毫秒级的高速交会拉宽为 **1.5 ~ 2.5 真实秒**，留给玩家充足的时间观察天体晨昏线与轨道高度，消除纯手速反应焦虑。

### 3. HUD 交互规格
* 屏幕右下角常驻 `[ BRAKE / 逆喷制动 ]` 按钮（仅轨道器模式可见）。
* 遵循硬约束：**`fireOn: 'press'` 按下即动作**，不依赖松手。
* 状态机：巡航待命（微光半透明）➔ 入窗激活（脉冲金光光环）➔ 按下瞬间点火爆闪并永久置灰（`EXHAUSTED`）➔ 错过窗口变暗失效。

### 4. 动态物理分支推演
* 玩家按下瞬间，物理系统以当前离散位置与速度为初值，瞬时注入反向冲量（$V - \Delta v \hat{v}$），调用 `simulate()` 在 **< 0.1 毫秒**内无缝重算剩余轨迹，实时刷新尾迹与结算归宿。

## 2.4 三种飞行结局演出

1. **碰撞坠毁 (Crash)**：
   - 刹车过晚或过猛导致近拱点跌破行星地表，探测器坠入大气层解体，镜头震颤与残骸火花，面板提示`[ 信号中断：碰撞坠毁 ]`。
2. **飞离脱离 (Escape)**：
   - 未在窗口内制动或制动不足，相对双曲线速度未被压制，探测器掠过天体渐行渐远，滑入无垠深空，面板提示`[ 任务未成：飞离脱离 ]`。
3. **稳定入轨捕获 (Capture · 核心成就)**：
   - 精确制动形成闭合椭圆轨道。
   - **不立即弹结算框**：探测器在闭合轨道上**平稳环绕公转 1 ~ 2 圈**，相机切入伴飞绕行特写长镜头，展示展开的仪器天线与星光；
   - 屏幕浮现`ORBIT INSERTION SUCCESSFUL / 环绕轨道捕获成功`，公转一圈半后优雅淡入结算数据（近拱点、远拱点、偏心率）。

核心设计理念：**“用同一套物理，去不同的地方；每一次任务，都是一次不可撤销的深空远征。”**

## 3.2 任务逐关设计规格与“三枚火箭 🚀🚀🚀”挑战

游戏废除传统陈旧的“三星”评价，改用充满航天工业美感的**“三枚火箭徽章（Rockets）”**：
* **🚀 基础达成（1 枚火箭）**：达成任务核心目标（飞掠经过或轨道捕获成功）。
* **🚀🚀 优异规划（2 枚火箭）**：燃料推进预算高效率控制（地面点火 $\Delta v$ 消耗在限定额度内）。
* **🚀🚀🚀 传奇领航（3 枚火箭）**：关卡专属的极限航天大师挑战。

### 1. L1 · 月球 · 启蒙 (Moon / Apollo & Chang'e)
* **背景**：人类迈向深空的第一站，地月系的摇篮。
* **物理场**：地月系（地球为世界中心，月球以真实周期绕地公转）。
* **三火箭挑战**：
  * 🚀 **使命达成**：成功飞掠或被月球引力捕获；
  * 🚀🚀 **精打细算**：发射点火消耗 $\Delta v \le 0.28$（节省 $> 20\%$ 推进剂）；
  * 🚀🚀🚀 **近月擦过**：近月点距离 $r_{peri} \le 0.015$（贴近月球表面安全边界掠过）。

### 2. L2 · 水手10号 · 潜行 (Mariner 10)
* **背景**：人类首次借力金星前往水星，开启了行星引力辅助的历史纪元。
* **物理场**：内太阳系（太阳、水星、金星、地球）。
* **三火箭挑战**：
  * 🚀 **双星连线**：借力金星并成功抵达水星；
  * 🚀🚀 **轨道优化**：初始点火消耗 $\Delta v \le 75\%$；
  * 🚀🚀🚀 **完美减速**：金星交会时相对速度降幅 $\ge 12$ 单位（高效前向借力）。

### 3. L3 · 帕克号 · 烈日 (Parker Solar Probe)
* **背景**：飞向太阳日冕极热地狱的“触日者”，人类制造的最高人造速度纪录保持者。
* **物理场**：太阳系内圈，太阳带有高亮日冕危险带（半径 $R_{corona} = 15$）。
* **三火箭挑战**：
  * 🚀 **触碰太阳**：近日点深入太阳日冕观测带（$r_{peri} \le 15$）且未撞毁；
  * 🚀🚀 **低耗入轨**：初始点火消耗 $\Delta v \le 80\%$；
  * 🚀🚀🚀 **极速狂飙**：近日点最高日心速度突破 $v_{max} \ge 60$ 单位。

### 4. L4 · 伽利略号 · 泊入 (Galileo)
* **背景**：人类第一艘真正驻留并环绕木星系统进行长期观测的轨道器。
* **物理场**：地球、木星巨型引力井；**载具为轨道器型 (Orbiter)**。
* **三火箭挑战**：
  * 🚀 **环绕捕获**：在制动窗口内成功按下 `[ BRAKE ]`，进入木星束缚闭合轨道；
  * 🚀🚀 **推进节制**：地面发射点火 $\Delta v \le 70\%$；
  * 🚀🚀🚀 **优美入轨**：入轨偏心率 $e \le 0.25$（形成近正圆的稳定停泊轨道）。

### 5. L5 · 新视野号 · 狂飙 (New Horizons)
* **背景**：直奔九大行星时代最后一颗未知行星——冥王星的极速信使。
* **物理场**：地球、木星（超强加速弹弓）、外边缘柯伊伯带深空。
* **三火箭挑战**：
  * 🚀 **飞向深空**：借力木星获得逃逸能量，成功抵达外边界；
  * 🚀🚀 **节约点火**：地面发射初速消耗 $\Delta v \le 75\%$；
  * 🚀🚀🚀 **引力狂飙**：经过木星加速后速度增幅 $\ge 15$ 单位，且逃逸末速度 $v_{end} \ge 40$。

### 6. L6 · 旅行者2号 · 奇迹 (Voyager 2)
* **背景**：人类航天史上绝无仅有的神迹，利用 175 年一遇的行星连珠，以单枚探测器连续拜访木星、土星、天王星与海王星。
* **物理场**：太阳系全景（木星、土星、天王星、海王星），需精准调校发射日期。
* **三火箭挑战**：
  * 🚀 **伟大巡游**：成功完成四星连续借力并飞出海王星轨道；
  * 🚀🚀 **黄金窗口**：初始发射点火 $\Delta v \le 80\%$；
  * 🚀🚀🚀 **四星全中**：四次行星交会均未发生任何碰撞且各星近心点精度 $\le 5\%$。

## 3.3 终章：暗淡蓝点 (Pale Blue Dot)

* **触发机制**：完成 L6（旅行者2号）后自动进入，作为全游戏的史诗谢幕。
* **影视化演播**：
  * 相机完全解除常规限制，跟随探测器朝逃逸反方向以长镜头一路拉远至深空 1000+ 单位；
  * 行星逐渐消隐于黑暗，太阳退化为一个耀眼的星点，地球按真实光学比例缩为仅数个像素的微弱蓝斑；
  * 浮现卡尔·萨根《暗淡蓝点》手稿名句与旅行者金唱片编码；
  * 结算卡显示玩家在全部 6 大任务中累计点亮的火箭总数（例如 `16 / 18 🚀`）。

# 四、 微缩 3D 太阳系选关与非线性探索

告别过时的 2×3 方块网格按钮，**主界面与选关界面直接融合为一座常驻交互式的 3D 微缩太阳系沙盘**。

## 4.1 3D 沙盘无缝延展
* 开场动画（`Opening.ts`）播完后，不再跳转黑屏或切界面，而是**自然悬停在 3D 太阳系全景**；
* 太阳在中央脉动发光，各大行星沿着发光的线稿轨道各自公转；
* 玩家可单指滑动旋转沙盘视角，双指缩放全局视野。

## 4.2 全息任务图钉 (Holographic Mission Pins)
* 6 个任务目的地行星上方悬浮发光的半透明**全息图钉与标牌**，图钉锚定在任务的【最终目的地】天体上：
  * **L1** ➔ 锚定在 **地球/月球** 上方，标牌 `L1 · 月球 · 启蒙`（终点：月球）；
  * **L2** ➔ 锚定在 **水星** 上方，标牌 `L2 · 水手10号 · 潜行`（终点：水星，借力金星）；
  * **L3** ➔ 锚定在 **太阳日冕层** 上方，标牌 `L3 · 帕克号 · 烈日`（终点：日冕危险带，借力金星）；
  * **L4** ➔ 锚定在 **木星** 上方，标牌 `L4 · 伽利略号 · 泊入`（终点：木星系统，轨道器泊入）；

# 六、 交互与控制原则

1. **单指全局触控**：
   * 屏幕任意区域按下并拖动即为瞄准，位移方向 = 发射方向，位移距离 = 发射力度（初速），无需精准抓取微小的探测器模型。
2. **动作按钮即时响应**：
   * 核心动作按钮（发射、制动、重试、返回沙盘）全部采用 `fireOn: 'press'`（按下即动作），配合模块级自维护时钟（`uiClock`）实现 0.5s 防重防丢保护。
3. **发射日期交棒守恒**：
   * 瞄准期调节时间轴影响 `clock`；按发射瞬间执行 `clock → t0` 交棒，保证世界物理时间与画面连续无跳变。
4. **多火箭持久化存档**：
   * 本地存档记录每个关卡已点亮的火箭数，支持随时重玩旧关挑战更高火箭评级。

# 七、 关卡入场影视化运镜与 2D 规划增强系统

为了让玩家在进入每个历史关卡时建立强烈的空间距离震撼，并在 2D 瞄准阶段获得清晰舒适的操控视野，建立以下关卡基线规范：

## 7.1 关卡入场 3D 影视化「倒叙/溯源运镜」
* **视听叙事设计（约 3.0 ~ 3.3 秒）**：
  1. **第一幕：终点目标星球特写（约 1.0 秒）**：
     * 关卡开启瞬间，镜头直接切至本次任务的**最终目标天体**（例如 L4 木星巨球、L6 海王星微光球体），展示其自转带纹与晨昏光晕；
     * 屏幕浮现任务代号与终点目标电传：`【勘测目标：木星系统 (Jupiter)】`。
  2. **第二幕：逆序航线飞掠（约 1.5 秒）**：
     * 相机高速拉起，沿着该关的引力借力路线**倒向飞掠沿途所有借力行星**（如 L6 从海王星一路逆向飞掠天王星、土星至木星；L2 从水星逆向飞掠金星）；
     * 星体在星空中呼啸后退，建立跨越几十个天文单位的宏伟星际纵深感。
  3. **第三幕：归巢与探测器特写（约 0.8 秒）**：
     * 镜头减速平滑俯冲至出发地（地球轨道上静静等待发射的探测器）；
     * 太阳翼与高增益天线微光闪烁，呈现【发射准备就绪】姿态。
  4. **第四幕：平滑切入 2D 规划界面**：
     * 运镜结束，视角自然平滑展开为 2D 轨道规划线稿层，玩家进入瞄准规划。
* **交互与防疲劳规则**：
  * **轻触即跳过 (Tap to Skip)**：运镜期间玩家在屏幕任意处轻触即可瞬间跳过，直接进入 2D 规划；
  * **重试不重放**：关卡内点击「重试本关」时不重复播放，仅从选关沙盘首次进入时触发。

## 7.2 2D 规划视图多级缩放与自适应包络
* **多级动态缩放**：
  * 左下角常驻矢量缩放控制组：
    * `[ + ]` 放大视口（聚焦出发地地月系或行星近心点，精细微调发射角度与初速）；
    * `[ - ]` 缩小视口（拉远俯瞰太阳系全貌，统揽远端会合窗口）；
    * `[ ⌖ ]` **一键自适应聚焦 (Fit View)**：自动计算包络盒，将「探测器当前位置」与「下一个目标天体」刚好完整呈现在屏幕黄金视野内。
  * **手势支持**：同时支持触屏双指捏合缩放 (Pinch-to-Zoom) 与双指平移。

## 7.3 全局 UI 按钮图标化体系 (SVG / VGNode)
* 告别局内生硬的文字框按钮，全面改用基于 Dora SSR 原生 `SVG` / `VGNode` 渲染的**极简线框矢量图标**：
  * **发射**：火箭升空 / 航天点火矢量图标；
  * **2D / 3D 视图切换**：正交平面网格图标 / 透视微缩天体图标；
  * **播放倍速**：快进箭头图标（`▶ / ▶▶ / ▶▶▶`）；
  * **时间流回退 / 加速**：时钟逆转 / 顺转快进图标；
  * **惯性 / 刹车模式**：自由滑行椭圆轨道图标 / 逆喷减速阻尼图标；
  * **实时逆喷制动**：主发动机喷火阻尼大号发光脉冲图标；
  * **缩放控制**：细线放大镜 `+` / `-` 与极简准星 `⌖`。
* 保证在任何手机/高分辨率屏幕下均具备 100% 锐利、高对比度的深空仪表感。

## 7.4 屏幕外目标雷达指示与常驻三火箭任务抽屉
* **屏幕外目标雷达指针 (Off-screen Target Beacon)**：
  * 缩放或平移后，当目标星球位于当前屏幕外时，屏幕边缘浮现半透明发光雷达指针，指向目标方向，并标注文案（如 `木星 · 4.8 AU ➔`）；
  * 点击指针可直接将视野自适应对准该目标。
* **常驻三枚火箭任务抽屉与实时达标反馈**：
  * 顶部常驻半透明任务状态栏，微缩展示 3 个火箭轮廓：
    * 🚀 **一星**：基础目标达成；
    * 🚀🚀 **二星**：发射推进剂限制（如 $\Delta v \le 70\%$）；
    * 🚀🚀🚀 **三星**：关卡专属大师级挑战；
  * **实时瞄准反馈 (Live Feedback)**：在 2D 拖拽拉伸预测线时，若当前点火量满足二星条件，第二枚火箭图标实时亮起金色微光；若超标则变灰，让玩家在放手前清晰预判能否斩获高星。
