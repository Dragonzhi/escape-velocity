# 一、 项目一句话与愿景

## 1.1 一句话定义
> **用一次发射，借行星的力，把一枚探测器送出太阳系。**

《单程》是一款面向竖屏移动端 / Web 端的纯物理轨道规划独立游戏。玩家扮演深空航天控制中心的领航员，在发射前利用有限的推进燃料与行星发射时间窗完成弹道规划；**发射之后，探测器由真实天体物理引力驱动，所有决定只能向前、不可撤销。**

## 1.2 设计北极星与核心情感
1. **“所有决定都只能向前，不可撤销”**（Forward-only Commitment）：
   - 不设自由飞行手柄，不设空中任意微调；
   - 玩家的操作极度克制：发射前的初速规划、发射日期的窗口微调，以及（若为轨道器）飞行临界期仅此一次的制动点火；
   - 所有的结果均由物理法则自然判定，带来纯粹的决定宿命感。
2. **“掠过行星被甩弯”是核心高潮**：
   - 探测器贴近行星近心点时，受行星深重引力牵引发生剧烈弯折与速度跃升——这是 3D 视觉与听觉给玩家最核心的奖励。
3. **“暗淡蓝点”的终局史诗**：
   - 游戏不是简单的打靶通关，而是以人类深空探测（Voyager、Galileo、Cassini、New Horizons）为叙事底色的浪漫史诗；
   - 历经重重引力弹弓飞出太阳系后，回望家园地球缩成一个像素的“暗淡蓝点”，完成一场壮丽的单程远征。

## 1.3 交付目标规格
* **引擎**：Dora SSR（v1.9.3+）
* **语言**：TypeScript（编译为 Lua 由引擎执行）
* **形态**：竖屏、单指触屏操控（自适应横屏/不同宽高比）
* **导出**：Web (HTML5) 并通过真机测试
* **开源协议**：AGPL-3.0-only
* **美术约束**：纯代码生成与自制 Low-poly glTF 几何模型 + 贴图，无第三方商业素材依赖。

# 二、 核心机制与双载具模式

## 2.1 规划与观赏的双视图体系
《单程》采用“**2D 规划线稿 ⇄ 3D 沉浸观赏**”的双层视听设计：

```text
[ 进关 / 瞄准阶段 ] ──────────> [ 发射瞬间 ] ──────────> [ 飞行与慢镜头特写 ] ──────────> [ 终点与结算 ]
   2D 俯视规划线稿                 自动平滑切入                   3D 动态跟随 / 伴飞镜头               3D 观赏 + 结果浮现
 (调方向 / 时间 / 读数)            (视角俯冲过渡)               (发光太阳 / 晨昏线 / 甩弯)            (重试回到 2D 规划)
```

* **2D 规划视图（Blueprint View）**：
  * 线稿轨道圆环、天体图钉与动态公转流动光点（光点流动方向 = 公转方向，速度 = 真实角速度）；
  * 目标天体到达判定圈、发射前预测线与高亮制动窗口；
  * 提供一眼可读的信息：下一站在哪、航线是否可达、何时发射、燃料预算、飞行耗时。
* **3D 观赏视图（Spectator View）**：
  * 真实 AU 比例空间、发光自发光太阳与大气光晕日冕面片；
  * 真实天体贴图与行星晨昏光影交界线；
  * 彗星式渐细粒子尾迹与掠过天体时的特写镜头。
* **切换机制**：进关/重试自动在 2D 瞄准，按下发射自动切入 3D 运镜，界面保留手动一键切换按钮。

## 2.2 载具双模式：飞掠器 vs 轨道器
为了还原深空探测的两大经典任务形态，游戏提供两种载具模式：

| 模式 | 现实代表 | 玩法机制 | 核心体验 |
|---|---|---|---|
| **飞掠型 (Flyby Probe)** | Voyager 1/2<br>New Horizons | $100\%$ 燃料预算全部用于地面发射初始冲量；松手发射后不再有主动操作，纯凭引力弹弓加速甩向下一站或深空。 | **“我借你的力，然后继续向前。”** |
| **轨道器型 (Orbiter Probe)** | Galileo (木星)<br>Cassini (土星)<br>MESSENGER (水星) | 预留一部分机动预算分配给在轨制动发动机（$\Delta v_{brake}$），初始发射冲量相应折减；**飞行途中赋予玩家仅此一次不可撤销的逆向制动机动**。 | **“我借你的力，然后决定留下。”** |

## 2.3 飞行期制动机动（方案 A：制动窗口机制）

在轨道器模式下，飞行不再是单纯的挂机等待，而是引入了类似《愤怒的小鸟》释放特技的临界心流：

```text
发射 ──(冷白虚线)──> [ 飞入目标引力井 ] ══(金色脉冲制动窗口)══> [ 飞离 / 逃逸 ]
                                 │
                         玩家按下 [ BRAKE ]
                                 ↓
                     逆向点火爆发，瞬时减速
                                 ↓
                ┌────────────────┼────────────────┐
                ↓                ↓                ↓
            Crash (坠毁)    Capture (稳定入轨)   Escape (逃逸)
```

### 1. 发射前预测线（分段呈现）
* **基础飞掠段**：冷白 / 浅青虚线，展示未经主动制动的自然飞掠轨迹。
* **制动窗口段（Braking Window）**：琥珀金脉冲发光光带。该段由纯函数预积分求得——**只要探测器在该段轨迹内按下制动，其剩余动能即可被引力捕获为稳定环绕轨道**（满足束缚能量 $E_{rel} < 0$ 且近拱点 $r_{peri} > R_{body} \cdot (1 + \text{安全缓冲})$）。

### 2. 飞行期慢镜头透镜联动（Slow-mo Lens）
* 当探测器飞抵目标天体引力影响区或接近制动窗口起点时，播放倍速平滑衰减至慢动作档位（`0.25x`），相机自动贴近天体形成特写；
* 将毫秒级的高速交会拉宽为 **1.5 ~ 2.5 真实秒**，留给玩家充足的时间观察天体晨昏线与轨道高度，消除纯手速反应焦虑。

### 3. HUD 交互规格
* 屏幕右下角常驻 `[ BRAKE / 逆喷制动 ]` 按钮（仅轨道器模式可见）。
* 遵循硬约束：**`fireOn: 'press'` 按下即动作**，不依赖松手。
* 状态机：巡航待命（微光半透明）➔ 入窗激活（脉冲金光光环）➔ 按下瞬间点火爆闪并永久置灰（`EXHAUSTED`）➔ 错过窗口变暗失效。

### 4. 动态物理分支推演
* 玩家按下瞬间，物理系统以当前离散位置与速度为初值，瞬时注入反向冲量（$V - \Delta v \hat{v}$），调用 `simulate()` 在 **< 0.1 毫秒**内无缝重算剩余轨迹，实时刷新尾迹与结算归宿。

## 2.4 三种飞行结局演出

1. **碰撞坠毁 (Crash)**：
   - 刹车过晚或过猛导致近拱点跌破行星地表，探测器坠入大气层解体，镜头震颤与残骸火花，面板提示`[ 信号中断：碰撞坠毁 ]`。
2. **飞离脱离 (Escape)**：
   - 未在窗口内制动或制动不足，相对双曲线速度未被压制，探测器掠过天体渐行渐远，滑入无垠深空，面板提示`[ 任务未成：飞离脱离 ]`。
3. **稳定入轨捕获 (Capture · 核心成就)**：
   - 精确制动形成闭合椭圆轨道。
   - **不立即弹结算框**：探测器在闭合轨道上**平稳环绕公转 1 ~ 2 圈**，相机切入伴飞绕行特写长镜头，展示展开的仪器天线与星光；
   - 屏幕浮现`ORBIT INSERTION SUCCESSFUL / 环绕轨道捕获成功`，公转一圈半后优雅淡入结算数据（近拱点、远拱点、偏心率）。

# 三、 六关独立任务舞台表

关卡设计遵循原则：**同一套物理，去不同的地方。** 从第一关起所有物理天体全部在场，不再有“这一关才引入新规则”的生硬切割；每关均从地球轨道出发，难度递进来源于：**航行距离、中继引力节点数量、以及发射窗口的严苛程度**。

## 3.1 关卡总览

| 关卡 | 代号 | 目的地 | 轨道半径 (AU比) | 中继节点 | 标配载具 | 核心课题与瞬间 |
|---|---|---|---|---|---|---|
| **L1** | 出发 | **月球** | 地月系近地 (0.2) | 0 | 太阳能板版 | **地月转移**：地心 2D 规划视角，近地入轨与引力捕获。 |
| **L2** | 修正 | **金星** | 0.72 AU (57.9) | 0 | 太阳能板版 | **向内坠落**：逆公转方向减速，对抗太阳深引力井，金星借力。 |
| **L3** | 弹弓 | **木星** | 5.20 AU (416.2) | 0 | 太阳能板版 (Juno型) | **引力巨物**：外太阳系门户，后向飞掠产生巨大加速跳跃。 |
| **L4** | 窗口 | **土星** | 9.54 AU (762.9) | 1 (木星) | RTG 核电池版 | **时间对齐**：必须用时间轴拨动相位，借木星单跳越过荒芜深空。 |

> **探测器硬件演进**：
> - 太阳能板版（L1 ~ L3）：适用于太阳辐射充沛的内太阳系与木星轨道；
> - RTG 核电池版（L4 ~ L6）：离开木星后太阳辐射极度微弱（$\propto 1/r^2$），换用放射性同位素温差热电发生器（RTG，旅行者号同款），机体天线全程动态逆向指向地球。

## 3.2 终章：暗淡蓝点 (Pale Blue Dot)

* **触发条件**：L6（海王星）达成成功结算后自动触发，不再单独列为一个关卡。
* **影视化演播**：
  * 相机解开常规夹紧限制，沿着探测器逃逸方向以指数级平滑拉远至极限深空（机位距太阳 1000+ 单位）；
  * 太阳缩成耀眼的星芒，金星、火星已不可见，而地球在浩瀚星海中缩成一个仅有数个像素宽度的微弱蓝光点（严格按真实投影比例，不人工放大）；
  * 画面浮现卡尔·萨根关于《暗淡蓝点》的致敬文字与旅行者金唱片编码；
  * 界面仅保留一颗静谧的`[ 返回选关 ]`按钮。

# 四、 视听系统与艺术规格

1. **真实天文尺度与视觉解耦**：
   * 物理轨道与运行周期严格由天文常数与开普勒定律导出（见 [`game/Scale.ts`](file:///c:/Users/32485/AppData/Roaming/IppClub/DoraSSR/escape-velocity/game/Scale.ts)）；
   * 视觉半径与 2D 图钉尺寸配置化解耦（见 [`game/Tuning.ts`](file:///c:/Users/32485/AppData/Roaming/IppClub/DoraSSR/escape-velocity/game/Tuning.ts)），确保在手机小屏幕上天体既能看清，又不失浩瀚空旷感。
2. **光影与天体表现**：
   * 太阳自发光：表面米粒与黑子贴图 + 始终面向相机的半透明日冕光晕面片；
   * 晨昏线：全局环境光压低至 0.12，单一定向平行光打出鲜明强烈的昼夜交界；
   * 土星环与天王星环：外置双面半透明贴图，天王星环保留 98° 垂直于公转平面的拟真轴倾。
3. **动态轨迹与流动感**：
   * 预测线：高对比度虚线 + 渐隐渐显，制动窗口以高明度脉冲琥珀金区分；
   * 飞行尾迹：仅保留最近采样点的彗尾式流线，头部亮点引导，尾部透明收窄。

# 五、 交互与控制原则

1. **单指全局触控**：
   * 屏幕任意区域按下并拖动即为瞄准，位移方向 = 发射方向，位移距离 = 发射力度（初速），无需精准抓取微小的探测器模型。
2. **发射按钮防抖与即时触发**：
   * 核心动作按钮（发射、制动、重试、选关）采用 `fireOn: 'press'`（按下即触发），配合模块级自维护时钟（`uiClock`）实现 0.5s 防重防丢保护。
3. **发射日期交棒守恒**：
   * 瞄准期调节时间轴影响 `clock`；按发射瞬间执行 `clock → t0` 交棒，保证世界物理时间与画面连续无跳变。
4. **单点无缝存档**：
   * 本地持久化仅记录 `unlocked=N`，通关自动解锁下一关，支持随时重玩旧关。
