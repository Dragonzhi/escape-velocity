## 二、B 剖面的物理数值（真实阿波罗停泊轨）

**锚点不变**：`1 AU = 80 单位` ⇒ `1 单位 = 1,869,973 km`；`SecPerGameSec = 1.8835e6`（1 游戏秒 = 21.8 天）。
地球 gm（游戏单位）= **0.21625**，月球 gm = **2.66e-3**。

| 量 | 真实值 | 游戏单位 |
|---|---|---|
| 停泊轨半径 | 200 km 高度 ⇒ 地心 6,571 km | **3.5140e-3 单位** |
| 停泊轨圆速度 | 7.788 km/s | **7.8448 单位/游戏秒** |
| 停泊周期 | **88.4 分钟** | 2.8145e-3 游戏秒 |
| TLI 点火 Δv（霍曼） | 3.133 km/s（阿波罗实测 3.05–3.15） | **3.1556 单位** |
| 到月球的转移时长 | **4.978 天** | 0.2283 游戏秒 |
| 一圈 : 转移 | — | **1 : 81**（这就是这一关的时间跨度） |

**已实测（Node，仓库同一份 `Gravity`/`LevelData`/`Scale`，2026-09-28）**

| 项 | 结果 | 结论 |
|---|---|---|
| 步长 26.5 真实秒（200 步/圈） | 停泊轨形状 ±1.5%、一圈后相对漂移 0.55% | ✅ 可用（100 步/圈漂 1.9%，50 步/圈直接崩 —— 与项目旧数据一致） |
| 转移段步数 | dt = 26.5 秒 ⇒ **21,099 步** | ⚠️ 现在是 2,400 步 ⇒ **8.8 倍**，预测线要限流 + 缓存天体位置 |
| 转移精度 | 与 dt = 5 秒参考解相差约 7,000 km（转移距离 1.8%） | ✅ 预测与飞行共用同一个 dt，「看到的就是飞到的」 |
| 月球相位 | 现值 154.7° ⇒ **0 解**；重解到约 **225°** 后大量候选落进容差 | ✅ 必须重解相位（见 B0） |
| 积分器 | 固定步长就够 | ✅ **不动 `Gravity.ts` 的积分格式** |

⚠️ **待机轨迹必须改成相对宿主解析求位置**：地球在一个停泊周期里走 `30 × 2.8145e-3 = 0.0844` 单位，
是停泊轨半径（3.514e-3）的 **24 倍**。用惯性轨迹循环播放会让探测器每个周期瞬移一次 ——
这个坑在「冻结时钟」时代被盖住了，时间一流就会现形（现在的 L1 同样有，只是周期是 0.43 秒）。

## 三、时间机制

| 项 | 口径 |
|---|---|
| 档位 | 整数指数 `pow`，界面上写作 `10^pow ×`；**速率 = 10^pow ÷ 1.8835e6 游戏秒/真实秒** |
| 默认 | **pow = 0（1×，现实 1 秒）**；进关即按此速率流动 |
| 按钮 | `◀ 减速` / `⏸ 暂停` / `加速 ▶`：加速 = pow+1（后面加个 0），减速 = pow−1，下限 0。状态型按钮 `fireOn: 'release'` |
| 暂停 | `paused` 进 `GameCore`（状态驱动，AGENTS 硬约束 5）；任何相态都生效，飞行中也停 |
| 谁在流 | `Aiming`（没在拖）/ `Armed` / `Flying` 都按档位流；**瞄准中（按下探测器附近并拖动）自动 rate = 0**；飞行段照旧再叠 `SlowMoFactor` |
| 发射自动提档 | **发射瞬间把档位提到 40,000×**（L1 的飞行观赏档，飞行 10.75 秒），读数上可见；之后玩家可自由改 |
| 档位上限 | L1：pow ∈ [0, 7]（1× ～ 1000 万×）；外圈关卡各自给（它们这一轮只求等价于今天的速率，不动手感） |
| Tuning 字段 | `aimClockRate` / `playback` / `playbackSpeeds` 退役 ⇒ `speedDefaultPow` + `speedMaxPow` + `flightSpeedPow` |
| 任务时钟 | HUD 显示 `T+ 天 时:分`，是 1× 下「时间在流逝」的唯一可见证据 |

**1× 的直接后果（已与用户确认）**：画面基本静止（探测器 9.3 天… 现在是 88.4 分钟一圈、
地球自转 24 小时一圈），要看见动必须自己按加速。这是物理正确的，不是 bug。

## 四、3D 呈现（发射前 = 环绕地球的卫星）

| 部位 | 口径 |
|---|---|
| 机位 | L1 专用「贴地球」机位：取景点 = **探测器 + 地球**（不再自动把月球装进画面），仰角按关卡给（约 20°，接近轨道平面）。实现上给 `Tuning.LEVEL_RUNTIME` 加 `aimCamera` 一组参数，取景仍走 `CameraRig` 的逐点半径求解器（不另写一套） |
| 视觉半径（`BODY_VISUAL_L1`） | 地球 0.03 → **≈0.0015**（否则探测器画在地球视觉球内部）；月球 0.012 → **≈0.0004**；探测器 0.0015 → **≈0.00015**（停泊轨 / 探测器视觉半径 = 23，读起来是「卫星在绕」）；太阳保持 0.8（80 单位外的亮星） |
| 探测器轨道环 · 3D | 半径 3.514e-3 的圈，用**投影折线**画（与到达圈同一套 `projectPolyline`，细线、固定像素宽），被地球挡住的半圈压暗 |
| 探测器轨道环 · 2D | `PlanView` 补画（半径从 `probeStart` 与宿主天体推出，不新增手填数） |
| 地球自转 | 按真实周期：86,400 真实秒 ÷ 1.8835e6 = **0.0459 游戏秒一圈**；角度对 2π 取模防浮点抖动。月球**潮汐锁定**（永远同一面朝地球） |
| 流动光点 | L1 一条都不放（唯一那条是 80 单位的日心轨道，与玩家无关）；同时把光点尺寸改成按关卡世界尺度归一，防止别的关踩坑 |

## 五、2D 呈现

- 两个圈：月球轨（0.2056）+ 探测器轨（3.514e-3）⇒ 半径比 **1 : 59**。
- **缩放上限 6× → 约 60×**（现成的 `zoomIn/zoomOut`，只改夹紧）；FIT 仍是「探测器 + 下一个目标」自适应。
- **屏幕外信标**（S8.4 已写好的 `beaconDraw`）从可选变成必需：缩到 60× 看停泊轨时，月球必然在画外。
- 地球的日心轨道圈按用户早前要求「不太明显地显示」：压暗；它上面的光点删掉。

## 六、HUD（全部保留 + 新增时间控制组）

保留：Δv 读数、惯性/刹车、2D/3D 切换、发射、倍速（并入时间控制组）、任务抽屉。
新增：`◀ 减速` / `⏸ 暂停` / `加速 ▶` + 档位读数（`40,000×` 或「1 秒 ≈ 11.6 小时」）+ 任务时钟。
布局：时间控制组常驻**左下角 y=170 行**，2D 缩放组留在 y=96 行 —— 两组不再抢同一行。

## 七、入场运镜

保留三幕，放慢到约 **6 秒**（目标特写 2.0s / 逆行飞掠 2.4s / 归巢 1.6s），缓动改 smoothstep，
结尾**落到「贴地球」机位**（不是自动取景），并接上「轻触跳过」（`skipIntroTour()` 已暴露但无人调用）。
