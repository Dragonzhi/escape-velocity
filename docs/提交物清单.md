### 4.2 录制步骤

1. **先确认构建是绿的**：`node tools/dora-build/build.mjs --all` 必须 **0 失败**（构建失败 = 引擎跑的
   `.lua` 还是旧的，会录到上一版画面）；再跑一次 `pwsh tools/engine-run.ps1 -Run Test/UnitRunner -WaitFile .agent/test-results/unit-summary.txt`
   确认 `passed=8 failed=0`。
2. **摆好窗口**：竖屏。用 `Test/SizeProbe.lua` 读 `View.size`（不要写死；横屏 2024×1230 / 竖屏 601×1066），
   需要改窗口大小用 `tools/input-inject/set-window.ps1`。
3. **录屏**：Windows 用 `Win+G`（Xbox Game Bar）或 OBS。**优先用 Web 导出包录**（没有引擎 dev 工具条，
   成片干净）；若只能在 IDE 里录，就把窗口摆到使底部那条「退出 / 刷新」工具条落在录制区之外，或后期裁掉底部约 60 px。
   目标 1080×1920（或 601×1066 放大），30 fps 即可。
4. **逐镜录，每镜录 3 条取最好的一条**：合成点击/触摸**会丢事件**（AGENTS.md 第 8 条：6 次点击只有 1 次进游戏），
   看到「点了没反应」就重来，别指望后期补。
5. **转码**（有 ffmpeg 时）：
   `ffmpeg -i raw.mkv -vf scale=1080:1920:flags=lanczos -c:v libx264 -crf 20 -pix_fmt yuv420p -movflags +faststart submission/demo-1080x1920.mp4`
   没有 ffmpeg 就用 OBS 直接设置输出分辨率 1080×1920 / MP4。
6. **自检**（逐条打勾）：① 时长 30–60 s；② 竖屏无黑边；③ 画面里**没有**引擎工具条、没有桌面图标；
   ④ 前 3 秒就能看出「太空 + 轨道 + 在飞的东西」；⑤ 有一处「被行星甩弯」的镜头（这是本作的核心瞬间）。
7. 把 mp4 放进 `submission/`，回到本清单把第 C 行改成 ✅。

### 4.3 还缺什么

- **阻塞在引擎上**：录制需要引擎跑起来（另外一个 Agent 正在改游戏代码），等它收工 + 构建全绿再录。
- 若「掠过慢动作」「2D 规划视图」「终章」在截止前落地，分镜第 3/5 镜和备用镜可升级；没钱做就按上表拍。
