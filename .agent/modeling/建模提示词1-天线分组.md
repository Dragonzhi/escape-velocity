# 建模任务：给探测器天线加一个"可旋转分组"（Probe_Voyager_v1.glb）

## 背景与用途

Dora SSR 游戏项目用 `Probe_Voyager_v1.glb` 做玩家的探测器。游戏运行时需要**每帧单独旋转天线部分**，
让大天线始终朝向"地球"。为此需要把天线的 8 个零件挂到一个分组空节点下，空节点的原点就是天线的俯仰转轴。
（其余部分保持刚性：机身 + 三根 RTG 吊杆 + 磁强计杆整体随飞行方向旋转，这是游戏逻辑已经实现的。）

## 工程与文件

- Blender 工程：导出 `Probe_Voyager_v1.glb` 的那个工程（当前版本 = 21 个网格物体挂在 `Probe_Voyager` 根下）。
- 导出目标：覆盖 `E:\BlenderWork\glb\Probe_Voyager_v1.glb`（游戏侧会重新拷贝入库）。

## 具体操作

1. 在场景里新建一个 **空物体（Empty，Plain Axes 即可）**，命名 **`Probe_Antenna`**（严格按此拼写）。
2. 把空物体**移动到天线转轴处**：建议取碟天线（Probe_Dish）后表面与三根支撑腿（Probe_DishLeg_1..3）的汇交点，
   大约在碟天线背面中心。这个点就是游戏里天线俯仰摆动的轴心——**原点放错，转起来天线会漂移**。
3. 把以下 **8 个物体**设为 `Probe_Antenna` 的子级（选中物体 → 再 Shift 选中空物体 → Ctrl+P → **Keep Transform**，
   保持各零件的世界位置完全不变）：

   - `Probe_Dish`（大天线碟面）
   - `Probe_Feedhorn`（馈源喇叭）
   - `Probe_FeedStrut_1` / `Probe_FeedStrut_2` / `Probe_FeedStrut_3`（馈源支撑杆）
   - `Probe_DishLeg_1` / `Probe_DishLeg_2` / `Probe_DishLeg_3`（碟面支撑腿）

4. **其余物体一律不动**，保持挂在 `Probe_Voyager` 根下：
   `Probe_Bus`、`Probe_Deck`、`Probe_EquipmentBay`、`Probe_Boom_1..3`、`Probe_RTG_1..3`、
   `Probe_MagBoom_Top/Bot`、`Probe_MagSensor_Top/Bot`。

## 红线（不要做的事）

- 不改任何物体的**命名**、网格、材质、修改器；
- 不改任何已有物体的**原点（Origin）与变换**——这次只"加一个空物体 + 改父子关系（Keep Transform）"；
- 不改导出朝向约定（与上一版完全一致：同样的 +Y up / 导出预设）；
- 不合并、不重排其它层级。

## 导出

选中 `Probe_Voyager` 根物体 → glTF 2.0 → .glb，设置与上一版导出相同，覆盖到
`E:\BlenderWork\glb\Probe_Voyager_v1.glb`。

## 自查清单（导出后确认）

- [ ] GLB 的 nodes 列表里出现名为 `Probe_Antenna` 的节点；
- [ ] 上面 8 个零件是 `Probe_Antenna` 的 children，且它们的世界位置与改动前一致（在 Blender 里肉眼核对一遍即可）；
- [ ] 其余 13 个物体（Bus/Deck/EquipmentBay/Boom×3/RTG×3/MagBoom×2/MagSensor×2）仍是 `Probe_Voyager` 的直接子级；
- [ ] 文件里没有任何网格、材质、命名的变化；
- [ ] 文件体积与上一版同量级（当前 43,596 字节，允许因层级略增，不应数量级变化）。

## 游戏侧会怎么用（给你上下文，不需要建模侧实现）

运行时找到 `Probe_Antenna` 节点后，每帧把它从"碟面朝上"向"地球方向"倾斜约 40–50°（方位角随探测器位置实时变化），
让大天线看起来始终回头指向地球。若转起来发现天线整体位移，基本可以断定是空物体原点没放在转轴上——回到第 2 步调整原点。
