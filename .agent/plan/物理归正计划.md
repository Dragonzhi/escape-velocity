## 1. 病根：KeplerK 和太阳引力对不上，差 42.7 倍

`game/LevelData.ts` 里 `SunGm = 72000` ⇒ 圆轨速度 `sqrt(72000/80) = 30`、周期应为
`2π·sqrt(80³/72000) = 16.76s`；但 `KeplerK = 1.0` 让行星周期走 `r^1.5 = 715s`——**慢了 42.7 倍**。

⇒ **行星不是被太阳引力带着走的，是被一条手设公式推着走的**。探测器飞真引力、行星走假运动，永远对不上。
L1 探测器默认坠日、引力弹弓收益只有 ~4%、关卡相位必须靠 `level-phases.mjs` 硬解、
「探测器绕地球」动力学上不可能稳定——全是这一个根结的果。

## 2. 归正口径：一套缩放，其余全部导出

保留两个锚点（决定手感，且本身就是正确的缩放值）：

| 锚点 | 值 | 导出 |
|---|---|---|
| 1 AU = 80 单位 | 长度尺度 | **L = 1.496e8 / 80 = 1.870e6 km/单位** |
| v_circ(80) = 30 单位/秒 | 速度尺度 | 时间尺度 **τ = 1.883e6 真实秒/游戏秒**，**1 游戏年 = 16.76 游戏秒** |

```
gm_game = gm_real × 5.425e-7
R_game  = R_real / 1.870e6
T       = 2π·sqrt(a³ / μ)        （删除 KeplerK）
a_game  = a_AU × 80              （真实 AU 比）
```

**自检**：月球周期 1.259s ⇒ 每年绕地球 **13.3 圈**（真实 13.4）✓；
木星引力弹弓偏转（b=20, v=26）= **10.2°**，与真实量级一致 ✓。

### 3.8 配置文件：视觉 / 物理彻底分家

新增 `game/Scale.ts`（物理尺度唯一来源）+ `game/Tuning.ts`（可调参数唯一入口）：

```
game/Scale.ts        // 只放推导，不放可调值
  L, TAU, K          // 1.870e6 km/单位、1.883e6、5.425e-7
  trueRadius(km)     // = km / L
  trueGm(km3s2)      // = mu * K
  period(a, mu)      // = 2π·sqrt(a³/mu)

game/Tuning.ts       // 所有"想调就调"的值集中在这里，带注释写明影响面
  PROBE_VISUAL_RADIUS  0.0015   // 只影响 3D 模型缩放，不参与碰撞
  BODY_VISUAL_RADIUS   { sun, earth, moon, venus, jupiter, ... }
  PLAN_PIN_PX          { sun 13, planet 8, probe 11 }   // 2D 图钉固定像素
  PER_LEVEL            { dvBudget, tolerance, timeWindow, escapeRadius,
                         rigClamp, aimSpeed, flybyPad }  // 每关一份
```

规则（写进开发手册）：

1. **`Body.radius` 只放物理真值**（碰撞 / 引力 / 容差判定），由 `Scale.trueRadius()` 算出，禁止手填
2. **视觉半径只进 `Tuning.BODY_VISUAL_RADIUS`**，只被 `Scene` 与 `PlanView` 读取；
   `PlanetVisualDef.displayRadius` 语义改为"视觉半径"，**删除"必须等于 Body.radius"的旧硬约束**
3. 旧硬约束的替代：**2D 到达圈画真实容差**（`Test/PlanViewTest` 加断言：
   到达圈半径 == goal.tolerance，不随视觉半径变化）
4. `LevelData.ts` 里不再出现任何手填的半径 / gm / 周期，全部由 `Scale` 算出

## 5. 风险

1. **规模**：动到 `Scale`/`Tuning`(新) + `Config/LevelData/Game/CameraRig/PlanView/Hud/Scene` +
   六个测试模块 + 三个扫掠工具。截止 9-29 23:59，**任何一步失败超过 3 次就提交当前可用状态并如实记录**。
2. **性能**：`PredictSteps` 62000（26 倍）。只在瞄准/日期变化时重算 ⇒ 单次数毫秒；
   但若将来改成每帧重算必爆帧，机制不能动。
3. **观感**：3D 里天体是点（用户已确认接受）；**视觉放大只在 3D 模型上做，不改变判定**——
   必须确认玩家不会因"看着能过"却撞不到而困惑，2D 到达圈是唯一判据。
4. **L1 节奏**：探测器 2.3 圈/秒；瞄准时时间冻结（现有机制），操作之间它跑得快。
5. **飞行时长**：L6 飞行 513 游戏秒（4× 下 128 真实秒）。需确认可接受，或给 L5/L6 默认 4×。
